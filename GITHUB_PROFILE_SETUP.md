## Publish the profile README

The prepared profile text is at profile-readme/README.md. To enable it on GitHub:

1. Create a **public** repository named exactly the account login: sl7187855-coder.
2. Add the contents of profile-readme/README.md as that repository's root README.md.
3. Save the suggested Bio above in the account's public profile settings.
4. Add the main project repository link once the Harness-RS repository exists.

GitHub only displays a profile README when the public repository name exactly matches the account login. A profile README repository is separate from the main project repository.
