# Hi, I'm Samuel

I'm building **Harness-RS**, a resource-conscious coding-agent runtime in Rust, together with the optional **Thomas Mobile Agent** Android companion.

### What I'm working on
- Rust agent runtimes, tool orchestration and provider streaming
- Safer tool execution: explicit approvals, sandboxing, auditability and secret hygiene
- Context, skills, memory, MCP/LSP integration and developer tooling
- Android automation with user-controlled accessibility and screen-capture permissions
- Making useful developer tools run on constrained Linux hardware

### Open source & collaboration

**Contributors and reviewers are welcome.** Harness-RS is an early-alpha project developed on a low-resource Linux x86-64 machine. Build times and long-running tests are hard to complete on that hardware, so reports from other computers, security reviews, documentation improvements and mock-based tests are especially valuable.

- [Harness-RS project](https://github.com/sl7187855-coder/harness-rs)
- Read the contributing guide and project status before picking up a task.
- Please never post API keys, access tokens, private endpoints or personal device data in issues or pull requests.

I value small, reproducible fixes, clear test evidence and honest documentation about what works and what still needs work.
