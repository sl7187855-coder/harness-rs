# Thomas Mobile Agent APK releases

This directory contains deliberately published, versioned test APKs and checksum sidecars. Other Gradle outputs, local build caches and signing keys are not committed.

The 0.5.3 APK is a debug-signed test build, not a production-signed app-store release. Its manifest version, package ID and SHA-256 must be verified before distribution. To reproduce it from source, follow mobile/agent-android/README.md. Do not install a file merely because its name claims a particular version.
